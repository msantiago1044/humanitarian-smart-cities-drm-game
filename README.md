## Overview

This interactive Web 2.0 application fulfills **Step 1 (Individual Dynamic)** of the Phase 2 Learning Guide:
> *"Explore additional sources and create a digital Web 2.0 game with at least 25 questions about international and national disaster risk management actors, including correct answers."*

### Key Features
1. **Interactive 25-Question Command Simulation:** Score tracking, streak counter, real-time accuracy, direct question navigator (1–25), and instant academic feedback citing the official frameworks.
2. **Interactive 3D Study Flashcards:** Flip cards covering all 25 national and international Disaster Risk Management (DRM) actors and mechanisms.
3. **Tutor Verification Mode (Complete 25 Q&A Catalog):** Searchable and filterable answer key displaying all 25 questions, options, marked correct answers, and academic justifications.
